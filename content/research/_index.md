---

Each of the 8 core software engineering disciplines below is tackled from two complementary perspectives: **SE4AI** (adapting software engineering to build reliable AI-based systems) and **AI4SE** (using AI to improve the software development process itself). A ninth, transversal theme — evidence-based assessment — supports all the others with systematic empirical validation.
